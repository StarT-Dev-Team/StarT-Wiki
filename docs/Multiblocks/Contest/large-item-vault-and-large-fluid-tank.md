## Summary

A pair of multiblock Super Tanks / Super Chests that store a huge amount of a single Fluid (**Large Fluid Tank**) or a single Item (**Large Item Vault**). The author pitches them at <IV>IV</IV> as a sidegrade to AE2 bulk cells, or at <HV>HV</HV> as an earlier alternative, and wants storage in the pack to be more "Greg-style".

## Mechanics

- Both multiblocks would work similarly to the PS: the structure has several tiers of internal component, which in the schematics are represented by Machine Casings (Large Item Vault) and Hermetic Casings (Large Fluid Tank).
- A special hatch would allow a direct connection to an AE system (an "ME Storage Hatch/Bus").
- The author set the tier to <IV>IV</IV> so that the two multiblocks become available at the same time as bulk cells.

## Large Item Vault

### Summary

A multiblock Super Chest that stores a huge amount of a single Item.

### Structure

According to the schematic, a 10 x 5 x 5 block structure: a Red Steel Casing frame with Laminated Glass faces around an inner 3 x 3 core of HV Machine Casings and EV Machine Casings. One end face carries an HV Input Bus, an HV Output Bus, an ME Output Bus, and an AE2 Controller block in the center. Block counts from the schematic: 78 Red Steel Casing, 96 Laminated Glass, 36 HV Machine Casing, 36 EV Machine Casing, 1 HV Input Bus, 1 HV Output Bus, 1 ME Output Bus, 1 AE2 Controller.

## Large Fluid Tank

### Summary

A multiblock Super Tank that stores a huge amount of a single Fluid.

### Structure

According to the schematic, a 5 x 6 x 5 block tower: Silicone Rubber Casing plates at the top and bottom, Laminated Glass walls, and an inner 3 x 3 column of Hermetic Casings, two layers of EV Hermetic Casings and two layers of HV Hermetic Casings. One face carries an HV Input Hatch, an HV Output Hatch, an ME Output Bus, and an AE2 Controller block. Block counts from the schematic: 38 Silicone Rubber Casing, 48 Laminated Glass, 18 HV Hermetic Casing, 18 EV Hermetic Casing, 1 HV Input Hatch, 1 HV Output Hatch, 1 ME Output Bus, 1 AE2 Controller.

## Notes from the thread

- Thread feedback pointed out that most players would just use AE2 bulk cells on a subnet for this, and that almost everyone sets up AE2 as soon as they can; others replied that filling bulk cells is nearly impossible and that super tanks in particular are lacking.
- It was suggested to place the multiblocks at <EV>EV</EV> so they can be used well before bulk cells. The author answered that they set them to <IV>IV</IV> so both become available at the same time; one reply noted that bulk cells may be fairly far into <IV>IV</IV>.
